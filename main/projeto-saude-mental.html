Sobre este protótipo

Este projeto demonstra recursos simples de bem-estar emocional. Não substitui acompanhamento profissional nem oferece atendimento de emergência.

Os registros e desafios ficam armazenados localmente neste navegador para fins de demonstração. Não são enviados a um servidor.
